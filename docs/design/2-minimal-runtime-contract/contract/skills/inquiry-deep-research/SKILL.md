# 研究方法示例

本 Skill 是给 Agent 阅读的方法资源，不是独立 CLI 或状态机解释器。本次只完成宿主提供的当前阶段，不自行启动下一阶段、不发出宿主保留事件、不修改执行状态数据库。

研究方法依次包括：澄清问题与检索范围、广泛发现来源、检查访问并留存内容、去重分类与覆盖检查、提取支持/反驳证据、综合报告。实际阶段顺序和可回退边由外部 Playbook 声明，当前执行入口会提供本阶段目标、已接受输入、工具权限和产物要求。

- 来源发现保留发现途径和对应子问题；达到范围或资源限制时说明停止原因。
- 来源访问失败同样记录；只有实际抓取工具产生的回执和快照才能作为已获取事实。
- 不编造工具回执、访问时间、正文、引用位置或检查结果。
- 将产物写入本阶段授权输出目录，按宿主的输出槽位交卷；不以聊天中的“已完成”替代产物。
- 新资料和冲突保留旧版本，区分材料不足与系统执行失败。
- 遇到权限或资料缺口，提交包含缺口的候选产物；是否补查、等待或结束由宿主检查与转移规则决定。
- 对报告声明限制和未决问题，来源可定位不等同于论证必然成立。

本目录仅为契约设计样例，不自动注册任何工具或授予网络权限。
