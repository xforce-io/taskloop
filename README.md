# TaskLoop

Skill-first、以 Task 为一等公民的轻量通用任务框架，通过面向目标的 Plan → Route → Execute → Evaluate → Replan 闭环协调第三方 Agent Harness 与外部工具。

项目当前处于总体架构讨论阶段，尚未实现运行时。术语以 [名词表](docs/glossary.md) 为准。

- [总体架构 RFC-0001 v0.1.0](docs/RFC-0001-architecture.md)：完整设计提案，含七层架构、任务闭环、接口、Skill 版本、可靠性、安全与最小实现验收。
- [总体设计 Issue #1](https://github.com/xforce-io/taskloop/issues/1)：需求、验收与评审入口。

RFC 当前为 Draft；设计发布不代表架构已获批准或运行时已通过测试。
